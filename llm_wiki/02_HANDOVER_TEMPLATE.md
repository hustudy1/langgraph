# 인수인계 문서 (HANDOVER)

> 사용법: 이 템플릿을 복사해 `llm_wiki/HANDOVER.md`로 저장하고, 꺾쇠 `<...>` 부분을 채운다.
> 모든 AI는 작업 시작 전에 이 문서를 읽고, 의미 있는 작업 단위가 끝나면 이 문서를 갱신한다.
> AI가 코드와 설정 파일에서 확인 가능한 항목은 직접 채우고, 모르는 항목은 비워두지 말고 `[UNKNOWN]`이라고 적는다.
> 비밀값은 절대 적지 않는다. 환경 변수명과 보관 위치만 적는다.
